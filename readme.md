# Semestral Project for WAC

---

**Téma:** Personálna správa, prehľad o zamestnancoch nemocnice, ich priradenie k ambulanciám a nemocničným oddeleniam, prehľad o výkonoch a správa osobnej dokumentácie.

---

#### Zamestnanec
- **Create:** Ako HR manažér nemocnice chcem vytvoriť profil nového zamestnanca s osobnými údajmi, kvalifikáciou a certifikátmi.
- **Read:** Ako HR manažér nemocnice chcem mať prehľad o všetkých zamestnancoch a efektívne ich vyhľadávať podľa oddelenia alebo špecializácie.
- **Update:** Ako HR manažér nemocnice chcem aktualizovať údaje zamestnanca pri zmenách (napr. nová pozícia, kontaktné údaje, certifikáty).
- **Delete:** Ako HR manažér nemocnice chcem archivovať profil zamestnanca pri ukončení pracovného pomeru.

#### Priradenie k oddeleniam
- **Create:** Ako vedúci lekár chcem priradiť zamestnanca k ambulancii alebo nemocničnému oddeleniu.
- **Read:** Ako vedúci lekár chcem zobraziť si aktuálne obsadenie oddelení a históriu priradení zamestnancov.
- **Update:** Ako vedúci lekár chcem upraviť priradenie zamestnanca pri rotáciách alebo organizačných zmenách.
- **Delete:** Ako vedúci lekár chcem zrušiť priradenie zamestnanca pri jeho preradení na iné oddelenie.

#### Evidencia výkonov
- **Create:** Ako personalista chcem evidovať odpracované hodiny a výkony zamestnanca (počet vyšetrení, operácií, služieb).
- **Read:** Ako personalista chcem generovať prehľady výkonov zamestnancov za zvolené obdobie a porovnávať ich medzi sebou.
- **Update:** Ako personalista chcem aktualizovať záznamy o výkonoch pri korekciách alebo doplnení chýbajúcich údajov.
- **Delete:** Ako personalista chcem archivovať staré záznamy o výkonoch pre potreby dlhodobého uchovávania.
